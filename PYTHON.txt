PYTHON
Python is a high-level, interpreted, and general-purpose programming language known for its emphasis on code readability and clean syntax. It is widely used across various industries, from web development and data science to artificial intelligence and automation. 

Python syntax is the set of rules that defines how programs are written and interpreted by the computer. Often compared to grammar in human languages, these rules ensure code is structured so the Python interpreter can execute it without errors. 

Key Syntax Elements

Indentation: Unlike many languages that use curly braces {} to group code, Python uses whitespace (indentation) to define code blocks. Standard practice is to use four spaces per indentation level.
Keywords: These are reserved words with specific meanings that cannot be used as variable or function names (e.g., if, else, for, while, def, class).
Comments: Code annotations for human readers that the interpreter ignores. Single-line comments start with a #, while multi-line comments are often written using triple quotes (''' or """).
Line Structure: Statements typically end with a newline character, so semicolons are not required to finish a command. Long statements can be broken across multiple lines using a backslash \.
Identifiers: Names for variables, functions, and classes. They must start with a letter or underscore, cannot start with a number, and are case-sensitive (e.g., Value and value are different).
Quotations: String literals can be enclosed in single ('), double ("), or triple (''' or """) quotes. 

Features of python
Simple and Easy to Learn: Python uses a clean syntax that closely resembles natural English, making it highly readable and beginner-friendly.
Interpreted: Code is executed line-by-line at runtime, which simplifies debugging and eliminates a separate compilation step.
Dynamically Typed: Variable types are determined at runtime, meaning you do not need to explicitly declare data types like int or string when creating variables.
High-Level: It abstracts complex system details like memory management and hardware interaction, allowing developers to focus purely on application logic.
 (Platform-Independent): You can write code on one operating system (e.g., Windows) and run it on others (e.g., macOS or Linux) without modification. 

Python Data Types
Variables can store data of different types, and different types can do different things.

Python has the following data types built-in by default, in these categories:
Numeric: int, float, complex
Sequence Type: string, list, tuple
Mapping Type: dict
Boolean: bool
Set Type: set, frozenset
Binary Types: bytes, bytearray, memoryview
Text Type:	str

1. Numeric Types
Integer (int): Whole numbers without a decimal point.
Example: x = 5
Float (float): Numbers containing one or more decimals.
Example: y = 3.14
Complex (complex): Numbers with a real and an imaginary part (denoted by j).
Example: z = 2 + 3j 

2. Sequence Types
String (str): A sequence of characters enclosed in single, double, or triple quotes.
Example: name = "Python is easy "
List (list): An ordered and mutable (changeable) collection of items.
Example: fruits = ["apple", "banana"]
Tuple (tuple): An ordered and immutable (unchangeable) collection.
Example: coords = (10, 20) 

3. Mapping Type
Dictionary (dict): Stores data in key-value pairs. It is mutable and ordered.
Example: user = {"id": 1, "name": "Alice"} 

4. Set Types
Set (set): Unordered and mutable collection with no duplicate elements.
Example: unique_nums = {1, 2, 3}
Frozenset (frozenset): An immutable version of a set.
Example: fs = frozenset([1, 2, 3])

5. Boolean Type
Boolean (bool): Represents truth values.
Example: is_active = True 

6. Binary Types

bytes: Immutable sequence of single bytes. Example: b = b"Hello"
bytearray: Mutable version of bytes. Example: ba = bytearray(5)
memoryview: Provides a way to access the internal data of an object without copying it. 

7. None Type
NoneType: Represents the absence of a value.

int	Represents whole numbers (positive or negative) without decimals.
float	Represents numbers with decimal points, used for precision values.
complex	Represents complex numbers with real and imaginary parts.
str	Used to store text or sequences of characters.
list	Ordered and mutable collection of items, allows duplicates.
tuple	Ordered but immutable collection of items.
set	Unordered collection of unique items
dict	Stores data in key-value pairs for fast lookups.
bool	Represents logical values used in conditions and decision-making.

Logical operators
Example:
and: Returns True if both statements are true. (5 > 3 and 10 > 5) is True.
or: Returns True if at least one statement is true. (5 > 10 or 10 > 5) is True.
not: Reverses the logical state. not(5 > 3) is False. 

Identity operators
Example:
Check if two variables refer to the exact same object in memory. 

is: x is y returns True if x and y share the same memory location.
is not: x is not y returns True if they are different objects. 

Membership operators
Example:
Check if a value exists within a sequence (like a list, string, or tuple). 
in: 'a' in 'apple' is True.
not in: 5 not in [1, 2, 3] is True
